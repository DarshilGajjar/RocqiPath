# QC gallery

Reference images for judging output. Every figure here is generated by
RocqiPath itself with `qc_enabled = true`, from non-identifiable tissue.

> **Contributions welcome, with one rule:** images in this gallery must contain
> no patient identifiers, no accession numbers, and no scanner label strips.
> See [SECURITY.md](../../SECURITY.md).

## What to look for

### Alignment

| Good | Bad |
| --- | --- |
| Tissue boundaries coincide, not merely overlap | Outlines match but internal structures shear |
| Vessels and glands correspond across stains | Error grows steadily across the slide |
| Residual error is small and directionless | Error is systematic in one direction |

Drift that grows across a slide usually means a magnification mismatch, not a
registration failure. Check `survey/` before tuning the backend.

### Tissue and core detection

| Good | Bad |
| --- | --- |
| One region per genuine tissue block or core | Folds and debris detected as tissue |
| Boundaries follow tissue, not the coverslip | Cores clipped at the edge |
| Core count consistent across stains | Faint IHC yields fewer cores than H&E |

Raise `min_circularity` for debris; raise `box_scale` for clipping; enable
`fallback_to_he` for the count mismatch.

### Patches

| Good | Bad |
| --- | --- |
| Reference and moving tiles show the same field | A consistent offset between the two |
| Tissue fraction distribution is broad and sensible | Everything at 0.0 or 1.0 |
| Blur distribution has a single mode | A long low-blur tail (out-of-focus scan region) |

A consistent offset means the canvases disagreed. Check
[coordinates and canvases](../concepts/coordinates-and-canvases.md).

### Stain normalisation

| Good | Bad |
| --- | --- |
| Colour variation between slides is reduced | Chromogen and counterstain are confused |
| Faint and strong staining remain distinguishable | Genuine intensity differences flattened |

If intensity is your measurement, consider counting on unnormalised images.

## Adding a figure

1. Confirm the source tissue is non-identifiable.
2. Save as PNG, at a readable size but under about 1 MB.
3. Name it `<stage>-<good|bad>-<short-description>.png`.
4. Add a row to the relevant table above saying what to look at.
