# `recipe.json` reference

The resolved plan. Generated by `rocqipath study plan` from the descriptor plus
the survey, with every setting fully resolved — nothing left as `None` or
"auto" for a pipeline to guess at run time.

Read it, edit it, diff it, commit it.

## Top level

| Key | Meaning |
| --- | --- |
| `study` | Study name. |
| `schema_version` | Recipe layout version. Bumped when a change invalidates existing stage output. |
| `generated_at` | UTC timestamp. |
| `rocqipath_version` | Package version that produced the plan. |
| `recipe_hash` | Twelve hex characters over the decision-bearing content. |
| `stages` | Per-stage resolved settings. |
| `slides` | Per-slide resolved settings, chiefly magnification handling. |
| `notes` | Decisions worth surfacing, such as slides dropped from a stage. |

## The hash

`recipe_hash` covers everything except `generated_at`, `recipe_hash`, and
`rocqipath_version`, so regenerating an unchanged plan produces an unchanged
hash. Change a patch size and the hash changes.

Every artifact records the hash it was produced under. That is what lets a
stage tell whether existing output is still current, and what lets a methods
section identify a run precisely.

## `stages`

### `tissue`

| Key | Default | Meaning |
| --- | --- | --- |
| `enabled` | `true` | Run this stage. |
| `mode` | `"wsi"` | `"wsi"` for ordinary sections, `"tma"` for core arrays. |
| `target_magnification` | from descriptor | Physical output zoom. |
| `detection_magnification` | `1.25` | Coarse detection zoom. |
| `min_area_fraction` | `0.005` | Smallest accepted region, as a fraction of slide area. |
| `preview_scale` | `0.2` | Preview JPEG scale. |
| `tif_compression`, `tif_quality` | `"lzw"`, `99` | Output TIFF encoding. |
| `skip_existing` | `true` | Skip regions whose outputs are already complete. |

### `alignment`

| Key | Default | Meaning |
| --- | --- | --- |
| `method` | from descriptor | `"valis"` or `"orb"`. |
| `reference_stain` | resolved | The registration target. |
| `moving_stains` | resolved | Stains warped onto it. |
| `patch_size` | `1024` | Registration working patch size. |
| `grid_density` | `1` | Control-grid density. |
| `qc_enabled` | `true` | Write QC figures to `qc/`. |
| `keep_diagnostics` | `true` | Retain backend diagnostic output. |

### `patches`

| Key | Default | Meaning |
| --- | --- | --- |
| `patch_size`, `stride` | from descriptor | Grid geometry, in target-grid pixels. |
| `dimension_tolerance` | `0.01` | Permitted reference/moving canvas disagreement. |
| `max_workers` | `1` | Parallel workers. |
| `tissue_threshold` | `0.0` | **Deliberately zero.** See below. |

### `stain`

| Key | Default | Meaning |
| --- | --- | --- |
| `normalizer` | from descriptor | `reinhard`, `macenko`, or `vahadane`. |
| `stains` | resolved | Stains to fit and apply. |
| `fit_min_tissue` | `0.1` | Minimum tissue fraction for a training patch. |
| `max_train_patches` | `1000` | Cap on fitting patches. |

### `counts`

| Key | Default | Meaning |
| --- | --- | --- |
| `chromogen_stains` | resolved | Stains declaring `chromogen = "dab"`. |
| `min_cell_area`, `max_cell_area` | `50`, `null` | Object size gates, in target-grid pixels. |
| `tissue_threshold` | `0.0` | **Deliberately zero.** See below. |

### Why the thresholds start at zero

Expensive stages measure; they do not decide. Extraction and counting write
every artifact with its properties, and quality filtering happens afterwards as
a [selection](selections.md). Setting these above zero discards data
irreversibly and gives up the ability to change your mind cheaply.

Raise them only when disk space genuinely forces it, and record why.

## `slides`

One entry per surveyed slide:

```json
"CRC-118__he__s01": {
  "case": "CRC-118",
  "stain": "he",
  "base_magnification": 40.0,
  "magnification_source": "override",
  "source_magnification": 40.0,
  "usable": true
}
```

`magnification_source` is the metadata key the value came from, `"override"`
when it came from `study.toml`, or `"missing"`. `usable` is `false` for slides
that are unreadable or scanned below the requested magnification; stages skip
them.

## Editing

Two ways, both equivalent:

```console
$ rocqipath study plan mystudy --set patches.patch_size=256 --set alignment.method=orb
```

```python
study.plan(overrides={"patches": {"patch_size": 256}})
```

Or edit `recipe.json` directly and re-run — nothing regenerates it unless you
ask. Re-running `plan` overwrites your edits, so keep durable changes in
`study.toml` and use recipe edits for experiments.
